This does not follow the typical implied semantics of versioning for softwares/codes/programs. Minor or Patch updates do not mean that they will be compatible with the same Major update versions.

The versioning format is MAJOR.MINOR.RECTIFICATION

A MAJOR release is anything that makes any Chloe Felina database generated via previous MAJOR releases will be completely incompatible with it.
A MINOR release is either additional functionalities being added or certain functionalities being removed or major changes on how data certain data is handled and stored and/or severe oversights and/or bugs being addressed.
A RECTIFICATION release is any changes that fixes a minor/niche bug/glitch, improvements, removal of redundant code, et cetera.

So, to oversimplify, MAJOR releases refer to changes that fundamentally alter how Chloe Felina works/operates; MINOR releases refer to functionality being added or removed and/or changes things that are considered to be "broken"; and RECTIFICATION releases are tweaks and/or minor fixes and/or improvements.
